# For Dory ❤️

This is a ready-to-upload romantic mini website.

Files:
- index.html = opening page
- memories.html = photo/reasons page
- letter.html = final letter
- style.css = design
- script.js = animations
- photos/ = your uploaded photos

Easiest way to publish:
1. Create a free GitHub account.
2. Create a new repository.
3. Upload everything inside this folder.
4. In the repository, open Settings → Pages.
5. Select Deploy from branch, choose main, and save.
6. GitHub will give you a public website link to send her.

Tip: Keep the repository private until you're ready. If the final website must be publicly viewable through GitHub Pages, the repository may need to be public depending on the account/settings.
